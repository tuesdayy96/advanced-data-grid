# Changelog

## 0.1.1 (2026-11-19)

- Updated the npm package README to show public installation commands and link to the live documentation.

## 0.1.0 (2026-11-19)

### Added

- Generic React DataGrid with ESM, TypeScript declarations and standalone CSS.
- Fixed-height row virtualization and sticky headers.
- Cell selection, keyboard navigation, and text, number and date editing.
- Multi-column sorting, column filtering and global search.
- TSV clipboard copy, column resize and pinning, and optional dividers.
- Playground and English and Korean documentation.

### Quality

- React 18 and 19 support with React and React DOM as peer dependencies.
- Chromium, Firefox, WebKit and Edge regression coverage.
- Grid focus and ARIA row metadata with automated accessibility checks.
- Server rendering and hydration coverage.
- Bounded rendered row counts and reduced cell formatting work.
- WebKit editing re-entry fix for editing sessions started before a previous render's effect runs.
