`height={480}` 또는 `height="60vh"`처럼 스크롤 영역의 높이를 제한하세요. 헤더는 위에 고정됩니다. 화면에 보이는 행과 위아래 여유 행(overscan)을 렌더링하고, 빈 공간을 나타내는 행이 전체 스크롤 범위를 유지합니다.

행 높이는 고정입니다. 가변 행 높이, overscan 변경이나 컬럼 가상화를 설정하는 공개 옵션은 없습니다. DOM에 표시되는 행 수는 화면 크기에 좌우되지만, 입력 데이터의 메모리와 정렬 비용은 입력 크기에 따라 늘어납니다. 플레이그라운드에서 **100,000행**을 선택하고 스크롤하며 **일치하는 행**과 **렌더링된 행**을 비교하세요.

[height와 rowKey](/docs/ko/api/data-grid)를 참고하세요.
