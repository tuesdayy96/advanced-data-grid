`enableSelection`을 켜면 셀 선택과 키보드 탐색을 사용할 수 있습니다. 클릭으로 한 셀을 선택합니다. 드래그 또는 Shift + 클릭으로 시작점을 기준으로 직사각형 범위를 선택합니다. 드래그 중 위아래 가장자리에 가까워지면 자동으로 스크롤됩니다.

| 입력                     | 동작                                                    |
| ------------------------ | ------------------------------------------------------- |
| 방향키 / Shift + 방향키  | 한 셀 이동 또는 시작점을 기준으로 선택 확장             |
| Tab / Shift + Tab        | 행 경계를 넘어 이동하고 양 끝에서는 그리드 밖으로 이동  |
| Enter / Shift + Enter    | Enter로 편집을 시작하지 않는 셀에서 아래 또는 위로 이동 |
| Home / End               | 현재 행의 첫 셀 또는 마지막 셀로 이동                   |
| Ctrl + Home / Ctrl + End | 그리드의 첫 셀 또는 마지막 셀로 이동                    |

화면 밖 셀로 이동하면 해당 셀이 보이도록 스크롤하며 스크롤만 할 때는 선택이 유지됩니다. 정렬이나 필터가 표시 순서를 바꾸면 행 키로 활성 셀을 찾아 범위를 한 셀로 줄이거나, 행이 사라졌으면 선택을 해제합니다.
