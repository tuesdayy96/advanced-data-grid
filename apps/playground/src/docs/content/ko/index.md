Advanced Data Grid는 대용량 로컬 데이터를 표시하고 조작하는 React 컴포넌트 라이브러리입니다. 제네릭 TypeScript API와 별도 스타일시트를 제공하며 React 18과 React 19를 지원합니다.

플레이그라운드는 동일한 공개 API로 직원 샘플을 표시하는 예제 앱입니다. 데이터 크기와 기능 설정을 바꿀 수 있고, 100,000행 중 실제로 렌더링되는 행 수를 확인할 수 있습니다.

- [지원 기능과 제약](/docs/ko/features)을 살펴보세요.
