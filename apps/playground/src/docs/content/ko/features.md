- [가상 스크롤](/docs/ko/guides/virtualization)은 화면에 보이는 행과 여유 행을 렌더링합니다. 스크롤하는 동안 헤더가 상단에 고정됩니다.
- [셀 선택 및 키보드 탐색](/docs/ko/guides/selection)은 단일 셀, 직사각형 범위, 자동 스크롤을 지원합니다.
- [셀 편집](/docs/ko/guides/editing)은 텍스트, 숫자, 날짜 입력과 검증 및 변경 콜백을 지원합니다.
- [정렬, 필터 및 전역 검색](/docs/ko/guides/sorting-filtering)은 전달한 행을 대상으로 동작합니다.
- [클립보드와 컬럼](/docs/ko/guides/clipboard-columns)에서 TSV 복사, 너비 조절, 고정, 세로 구분선을 설명합니다.

## 현재 제약

행 높이는 고정이며 가상화는 행에 적용됩니다. 정렬, 필터, 검색, TSV 생성은 클라이언트에서 실행합니다. 클립보드는 복사를 지원하며 스프레드시트 붙여넣기, XLSX 내보내기와 실행 취소는 현재 API 범위 밖입니다. 좁은 화면에서는 고정 컬럼의 너비에 따라 고정이 일시 해제될 수 있습니다.
