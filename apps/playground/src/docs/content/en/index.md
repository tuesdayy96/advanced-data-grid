Advanced Data Grid is a React component library for displaying and interacting with large local datasets. It ships a typed generic API and a separate stylesheet. It supports React 18 and React 19.

The Playground is an example application. It uses the same public library API with sample employee data and lets you vary dataset size and feature flags. Use the Playground to inspect the number of rows rendered with 100,000 source rows.

- [Explore the supported features and limits](/docs/en/features).
